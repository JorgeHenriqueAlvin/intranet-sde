# Intranet SDE

Portal interno da Secretaria de Desenvolvimento Econômico da Bahia.

## Estrutura atual

- `index.html` — primeira versão visual e responsiva da intranet.

## Publicação

O projeto foi preparado para publicação como site estático na Vercel.

Ao importar este repositório na Vercel, utilize a raiz do projeto (`./`) e deixe o framework como **Other**. Não é necessário comando de build para esta primeira versão.

## Próxima evolução

- autenticação de servidores;
- busca real de documentos e conteúdos;
- integração com sistemas internos;
- notícias e comunicados administráveis;
- diretório de setores e contatos;
